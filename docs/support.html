Support

Install, update, and troubleshoot your apps.

Install or update

  1. Choose your app on GitHub Releases.
  2. Download the APK matching your device and verify the checksum in the release notes.
  3. Open the APK and follow Android’s installation prompt.

Installation failed

Check the Android version, architecture, and whether the download completed. An update must match the installed app’s package name and signer. If the signer differs, stop and check the release source before uninstalling, as uninstalling can remove app data.

Online features unavailable

Downloads can still be available here during service outages. If sign-in or payments fail, record the app version and error. Keep verification codes and payment details private.
